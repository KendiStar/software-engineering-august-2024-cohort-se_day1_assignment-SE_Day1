Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
UNIT ; Tests individual components ie functions, classes, modules of the software in isolation. Importance; it detects bugs early ,ensures each part works correctly before intergration. 
INTERGRATION TESTING; verifies that different modules or components work together correctly. It ensures smooth communication between various parts of the system. 
SYSTEM TESTING ; Evaluates the complete software system against functional and non-functional requirements. Ensures the software works as a wholebefore release.
ACCEPTANCE TESTING ; Confirms the software meets business and user requirements before deployment. It validates that the system is ready for real- world use.
